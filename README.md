# Memory Game

Игра на поиск пар: на поле 16 карточек с 8 разными изображениями, каждое встречается дважды. Нужно открывать карточки по две и находить все пары за наименьшее число ходов.

## Возможности

- 16 перемешанных карточек, закрытых одинаковой рубашкой
- Счётчики ходов и найденных пар
- Несовпавшая пара закрывается через секунду, пока она открыта, другие карточки выбрать нельзя
- Кнопка «Новая игра» в любой момент перемешивает карточки и обнуляет счётчики
- Модальное окно победы с итоговым числом ходов
- Таблица лидеров: 10 лучших результатов (место, ходы, дата), сохраняется в `localStorage`
- Модальные окна закрываются кнопкой «Закрыть», кликом по фону или клавишей Escape

## Запуск локально

Сборка и установка зависимостей не нужны.

1. Склонируйте репозиторий:
```
   git clone https://github.com/VIKTORIYA-S/memory-game.git
```
2. Перейдите в папку проекта:
```
   cd memory-game
```
3. Переключитесь на ветку с приложением:
```
   git switch memory-game
```
4. Откройте файл `index.html` в браузере (двойным кликом или через «Открыть с помощью»).
